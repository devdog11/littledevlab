# littledevlab

## Git and GitHub attribution

- Do not add attribution to commits or pull requests: no `Co-Authored-By: Claude` trailer, no `Claude-Session:` link, no "Generated with Claude Code" line.
- Commit messages and PR descriptions describe the change only.
- `.claude/settings.json` enforces this with `attribution.commit` and `attribution.pr` set to empty strings. Keep it.
