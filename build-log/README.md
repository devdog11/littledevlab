# Build Log

Short records of what changed in LittleDevLab and why it mattered. Browse the dated Markdown files here, or read the [website Build Log](../build-log.html).

Files are named `YYYY-MM-DD-NN-slug.md`. Each entry includes a date, time, title, tags, and a commit reference when available. Entries describe work at the time it was recorded; they are not current operating instructions.

The website page is maintained separately from these Markdown files.
